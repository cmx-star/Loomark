# 2026-08-24

## 修复 5 个 P1（大文件编辑链路）

- **索引预览丢正文**：`markdown_index.cpp` 现在为 Paragraph/CodeFence 采集 block.text，新增 `maxBlockTextBytes`（默认 8KiB）与 `textTruncated` 标记；GUI 渲染截断块时追加 "…"。
- **窗口起点边界**：新增 `alignWindowStart()`（main_window.cpp），任意跳转目标前移到 UTF-8 字符边界且不落在 CRLF 中间；`readWindow` 调用之。
- **流式保存**：core 新增 `AtomicFileWriter`（临时文件 + commit 原子替换 + 析构清理）；`writeCurrentDocument` 用 `streamCopyRange` 分 1MiB 块拼接头/窗/尾，不再全文进内存。
- **打开/保存不阻塞 UI**：core 新增 `statFile()`（size/tier/BOM，不扫描）；换行符全量分类移入新后台线程 `FileInspectThread`（gui/file_inspect_worker.*）；保存前 `completeInspection()` 等待结果，保存后用 statFile+沿用样式替代二次全扫。
- **后台线程关闭协议**：`inspectFile`/`buildPreviewIndex` 支持 cancelFlag 协作取消；两个 QThread 子类都有 cancel()+析构等待；MainWindow::closeEvent 调 shutdownBackgroundWork()。
- 测试：core_tests 新增段落/代码块文本断言、文本上限与取消测试、AtomicFileWriter 提交/中止测试。ctest 3/3 通过。

关键决策：FileInfo 新增 `newlineStyleKnown` 字段区分"未检测"与"None"；取消的索引结果直接丢弃不渲染。
