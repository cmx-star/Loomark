# M12 流式保存与撤销预算

## Goal

批次3 M12 收官：后端快照流式保存、保存恢复点、撤销内存预算与外部指纹复核；
完成 **F02「300MB 桌面完整编辑」** 端到端验收（打开→编辑→搜索→替换→保存→重载）。

## Requirements

- 恢复点：后端以版本号维护保存点（savedVersion_）；isDirty() = 版本漂移；
  保存成功后归零
- 外部指纹复核：装载时与每次成功保存时记录磁盘内容基线指纹；再次保存前
  流式重算磁盘指纹比对，不一致 → 拒绝保存（异常报「外部修改」），原文件不破坏；
  另存为新目标不复核
- 撤销内存预算：增量累计撤销动作字节量，超过预算（默认 64MiB）清空撤销历史并
  发出信号（内存上界换可预期行为，恢复点已落盘）；预算可配置（测试用）
- 300MB 端到端（F02）：后台装载 → 编辑（插入/替换）→ 搜索命中 → 保存（流式原子）
  → 重载复核 → 磁盘字节校验
- GUI：撤销预算耗尽提示状态栏

## Out of Scope

- 会话恢复日志（批次 5 M18）
- DocumentSession（批次 4 M13）

## Acceptance Criteria

- [ ] 恢复点单测：装载→脏→保存→干净→版本递增链
- [ ] 外部指纹复核单测：装载后外部改盘 → save 抛异常且原文件字节不变；
  另存为新路径成功
- [ ] 撤销预算单测：小预算下超额编辑触发清空（canUndo=false）且后续编辑正常
- [ ] F02 端到端（300MB 样本）：装载→编辑→搜索→替换（确认门）→保存→重载
  全链路通过，保存期间原文件在临时文件提交前不被触碰
- [ ] 全量 ctest 通过；git diff --check 通过
