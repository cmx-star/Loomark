# M14 标签页模型

## Goal

批次4 M14：在 M13 会话层之上提供多标签工作区——每个 Normal 档文档一个会话标签；
支持打开、关闭（含未保存确认）、排序（拖拽）、同路径去重与未保存标记。
切换标签不复制文档正文（切换即切换编辑器页面）。

## Requirements

- 标签栏（QTabBar，可拖拽排序、可关闭按钮）：一标签 = 一个 DocumentSession
- 同路径去重：打开已打开的路径 → 激活既有标签而非重复装载
- 未保存标记：脏会话标签显示 • ；保存后清除
- 关闭确认：关闭脏会话 → 保存/放弃/取消；取消中止关闭
- 大档位 windowed 文档保持现状（单文档、无标签），Normal 标签可在切回后继续使用
- 固定：右键菜单固定/取消固定，固定标签前移

## Out of Scope

- Workspace 文件树/最近文件（M15）
- 统一命令系统（M16）
- 会话持久化（M17）

## Acceptance Criteria

- [ ] 多标签打开/切换/关闭/去重/未保存标记 GUI 测试通过
- [ ] 切换标签后两个会话的缓冲内容保持各自正确（不复制正文的结构性验证）
- [ ] 现有全部测试无回归；git diff --check 通过
