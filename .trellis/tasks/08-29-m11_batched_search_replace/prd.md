# M11 大文件分批搜索替换

## Goal

批次3 M11：在 Scintilla 后端上实现分批搜索与批量替换——结果分批返回、单批与总量上限、
正则超时保护、大操作成本预估；超过 32MB 的修改必须先经用户确认。300MB 文档搜索全程可取消。

## Requirements

- 分批搜索 API：从指定字节偏移开始搜索，返回单批命中（上限可配）、下一批起点、是否已扫完
- 结果上限：单批 maxResults 上限 + 超限截断标志
- 正则超时：每批限定目标窗口与时间预算，超预算停止并报告 timeout 标志
- 可取消：cancelFlag 在批间检查，取消后立即返回
- 替换：基于 apply() 的批量编辑（复用 M09 版本/范围/重叠校验与撤销组）
- 成本预估与确认门：estimateReplace 返回受影响字节数；> 32MB 需显式 confirm 才执行
- GUI：基础查找/替换栏（字符串与正则、查找下一个、全部替换含成本确认）

## Out of Scope

- 流式保存、撤销内存预算（M12）
- 搜索结果高亮指示器（延后）

## Acceptance Criteria

- [ ] 分批搜索单测：批间续扫正确、单批上限与 truncated、跨块命中不漏
- [ ] 正则搜索可用且超预算时返回 timeout 标志（300MB 样本实测可取消）
- [ ] 替换走 apply()：版本过期/范围非法/重叠错误语义不变；单次替换 = 单撤销组
- [ ] estimateReplace：> 32MB 时拒绝执行除非 confirm=true
- [ ] 300MB 样本搜索实测：可取消、取消及时返回
- [ ] 全量 ctest 通过；git diff --check 通过
